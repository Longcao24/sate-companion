SATEDesign System v1.0.0

SATE Design System

Every token and component, rendered. Tokens were measured from what the clinical web app actually ships — not from its config files, which disagree with it. See README.md for the audit.

Using this in a new tool? Link sate.css for plain HTML, or extend tailwind.preset.js for React. Then run node verify.mjs ./src to catch colour drift before it ships.

Annotation palette

Clinical vocabulary, not decoration. A pause is this blue in every SATE tool, forever — never reassign one, and never borrow one because it looks right.

we went to the park and um the the doggy runned away — no, outside yesterday

Pause Filler Repetition Mispronunciation Morpheme Revision Utterance error Morpheme omission

Always pair the swatch with its word. Around 1 in 12 men has a colour-vision deficiency, and clinicians make judgements from this.
